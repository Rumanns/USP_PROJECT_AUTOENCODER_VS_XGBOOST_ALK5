### USP\_TCC

A ideia é testar o XG boost e um Autoencoder, para identificar compostos ativos contra o alvo ALK-5, uma proteína relevante no tratamento do câncer, quando em estado médio/avançado.



### Sobre o Projeto 📋

*O projeto tem o objetivo de agilizar a descoberta de ativos contra o alvo ALK-5. Permitindo que um possível tratamento seja mais rapidamente feito contra o câncer.*



### Começando 🚀

#### Pré-requisitos

ANACONDA, Python, XG Booster



#### Instalação

O pacote Anaconda pode ser adquirido de maneira gratuita no site da própria iniciativa (https://www.anaconda.com/download)

Bibliotecas: xgboost, sklearn, numpy, pandas, tensorflow, matplotlib, seaborn, pickle,



#### Uso Básico

1. ENTRAR NO PROMPT DO ANACONDA.

2\. ENTRAR NA MÁQUINA VIRTUAL DO PYTHON NO CONDA, QUE AQUI É A "ia\_project".

3\. INSTALAR OS REQUISITOS, BIBLIOTECAS E TALS.

4\. DEPOIS NAVEGAR NO PROMPT ATÉ A PASTA ONDE O "main.py" ESTÁ

5\. DEPOIS RODAR NO PROMPT DO ANACONDA UM "python main.py"
